# Если nginx не поднимается: «образ nginx-brotli не найден»

Так бывает, когда уборщик образов (`cogcore-docker-prune.timer`, каждый день в
04:30, `docker image prune -af`) застаёт момент, когда контейнер nginx
пересоздаётся: на образ в эту секунду никто не ссылается, и его удаляют.
Собрать заново можно — но это двадцать минут и работающий интернет, а сайт в
это время лежит.

Поэтому есть слепок образа. Восстановление — одна команда:

    sudo docker load -i /home/salex/backups/nginx-brotli/nginx-brotli-1.27-alpine.tar.gz

⚠ Путь именно этот, ВНЕ рабочего дерева репозитория. Копия лежит и рядом, в
`nginx/brotli/`, но полагаться на неё нельзя: самолечение авто-деплоя
выполняет `git clean -fd`, и весь каталог `nginx/brotli/` вместе со слепком
удаляется — проверено `git clean -nd` 05.09, в списке значилось
«Would remove nginx/brotli/». Страховка, лежащая в зоне поражения, — не
страховка. Внутренняя копия защищена от этого только правилом в `.gitignore`
на `*.tar.gz`, и то лишь после того, как это правило доедет до сервера.
    sudo docker compose -f /opt/cognitive-core/docker-compose.yml \
      -f /opt/cognitive-core/docker-compose.prod.yml \
      -f /opt/cognitive-core/docker-compose.override.yml up -d nginx

Проверка, что поднялось и сжатие работает:

    curl -s -o /dev/null -w '%{size_download}\n' -H 'Accept-Encoding: br'   https://ai-salex.ru/login
    curl -s -o /dev/null -w '%{size_download}\n' -H 'Accept-Encoding: gzip' https://ai-salex.ru/login

Первое число должно быть меньше второго. Если равны — brotli не работает:
значит поднялся обычный `nginx:1.27-alpine`, в нём модуля нет вовсе.

## Если слепка тоже нет — собрать заново

Рецепт: `nginx/brotli/README.md` (ветка `docs/nginx-brotli-reproducible`).
Версия обязана совпадать с боевой — 1.27.5.

⚠ На этом канале сборка падает на загрузке исходников: `RPC failed... early
EOF`. Лечится правкой `Dockerfile.alpine` перед сборкой — клон делаем
поверхностным и по HTTP/1.1:

    git -c http.postBuffer=524288000 -c http.version=HTTP/1.1 clone --depth 1 ...

Без этого первый заход почти наверняка оборвётся — проверено 04.09.

## Совсем крайний случай

Вернуть обычный образ и жить без brotli, пока не почините:
в `docker-compose.override.yml` заменить `image: nginx-brotli:1.27-alpine`
на `image: nginx:1.27-alpine`, поднять сервис. Сайт заработает, страницы станут
тяжелее примерно на пятую часть — но это лучше, чем лежащий сайт.
