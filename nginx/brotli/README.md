# Образ nginx с brotli: как его собрать заново

`nginx/nginx.conf` содержит `load_module ngx_http_brotli_*.so`. Штатный
`nginx:1.27-alpine` этих модулей **не содержит вовсе** — директива `brotli` в
нём не существует, и nginx с таким конфигом не стартует. Не деградирует до
gzip, а отказывается запускаться.

Поэтому контейнер поднимается на локально собранном образе
`nginx-brotli:1.27-alpine`, который выбирается в `docker-compose.override.yml`.

## Зачем этот файл

05.09 выяснилось, что образ существовал **только как локальный слой на диске
сервера**: рецепта сборки не было ни в репозитории, ни где-либо ещё. Связка
разорвана на три части, и каждая по отдельности выглядит безобидно:

| часть | где живёт | что если потерять |
|---|---|---|
| `load_module` | в git | nginx стартует без сжатия |
| выбор образа | `docker-compose.override.yml`, в `.gitignore` | nginx получает штатный образ и **не стартует** |
| сам образ | локальный слой docker | пересобрать нечем |

И сверху: `cogcore-docker-prune.timer` ежедневно в 04:30 выполняет
`docker image prune -af`. Пока контейнер существует, образ защищён ссылкой на
него. Но в окне между удалением старого контейнера и созданием нового (любой
`compose down`, пересоздание сервиса, неудачный выкат) образ ничем не
удерживается, и очистка снесёт его безвозвратно.

Риск узкий, последствие полное: nginx не поднимется, и восстановить будет
нечем. Этот файл закрывает третью часть — теперь образ воспроизводим.

## Сборка

Официальный сборщик модулей от nginx, та же версия, что в проде (1.27.5,
`DYNPKG_RELEASE=1`):

```bash
git clone --depth 1 https://github.com/nginx/docker-nginx /tmp/docker-nginx
cd /tmp/docker-nginx/modules
docker build --build-arg ENABLED_MODULES=brotli \
             --build-arg NGINX_FROM_IMAGE=nginx:1.27-alpine \
             -t nginx-brotli:1.27-alpine .
```

⚠ На этом канале первый заход почти наверняка оборвётся на загрузке
исходников: `RPC failed… early EOF` (проверено 04.09). Лечится правкой
`Dockerfile.alpine` перед сборкой — клон поверхностный и по HTTP/1.1:

```
git -c http.postBuffer=524288000 -c http.version=HTTP/1.1 clone --depth 1 ...
```

⚠ Версия обязана совпадать с боевой — 1.27.5. Модуль собирается под
конкретную сборку nginx и при расхождении не грузится по несовместимости ABI:
nginx не стартует, а сообщение будет про модуль, не про версию.

Проверка, что модули на месте:

```bash
docker run --rm nginx-brotli:1.27-alpine ls /etc/nginx/modules/ | grep brotli
# ngx_http_brotli_filter_module.so
# ngx_http_brotli_static_module.so
```

Поднимать nginx после пересборки образа — только своим сервисом, без
пересоздания соседей:

```bash
cd /opt/cognitive-core
docker compose up -d --no-deps nginx
```

⚠️ Пересоздание nginx это не reload: он обязан отрезолвить все upstream при
старте, и если хоть один контейнер недоступен, nginx не поднимется вообще.

## Откат

Убрать две строки `load_module` из `nginx/nginx.conf` и вернуть
`image: nginx:1.27-alpine` в override. Сжатие вернётся к gzip — он остаётся
в конфиге запасным и настроен.

## Замер, ради которого всё это

03.09, страница процессов: 1481 КБ без сжатия, 433 КБ gzip, brotli примерно на
пятую часть меньше gzip. Уровень 6, а не 11: одиннадцатый даёт единицы
процентов сверх и берёт в разы больше процессорного времени — на четырёх
ядрах, где живут ещё сорок контейнеров, это плохой размен.
